## 1. Purpose

Separate Platform Admin module (not a Dashboard section) for document records
associated with Astrologers, Assistants, and other permitted platform entities.

## 2. Approved basic scope

- Uploaded document list
- Related User / Astrologer / Assistant ID
- Document Type (if provided)
- Uploaded Date / Time
- Uploaded By
- View / Preview
- Download

## 3. Rules

- Astrologer documents are secondary and are **not** a prerequisite for
  providing services.
- No mandatory document types and no verification approval workflow are
  defined.
- The Astrologer App profile shows verification statuses and a re-upload
  option (Astrologer `AD-83`, `AD-85`); KYC steps are open there (`AP-04-01`).
